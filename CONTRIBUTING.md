# Contributing | 参与贡献

欢迎提交问题报告和改进建议。修改 skill 指令或参考资料时，请同时维护英文与简体中文版本，并链接对应的官方资料。

Issues and improvements are welcome. When editing skill instructions or references, update both English and Simplified Chinese and link to the relevant official documentation.

提供可复现的产品版本、操作系统、相关命令和脱敏后的结果。示例请使用虚构的 VM 路径、主机名、IP 地址和账号；凭据、私钥、令牌与个人机器信息保留在本机。

Include reproducible product versions, operating system details, relevant commands, and sanitized results. Use fictional VM paths, hostnames, IP addresses, and account names in examples. Keep credentials, private keys, tokens, and personal machine details local.

保持改动聚焦、说明用户能观察到的效果，并确认链接仍指向官方文档。

Keep changes focused, describe the result a user can observe, and check that links still point to official documentation.
